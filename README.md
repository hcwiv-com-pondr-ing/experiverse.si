Part of the ecosystem whose home is [tsiyongrid.com](https://tsiyongrid.com), by Henry C. Weismann IV
([STATEMENT.md](STATEMENT.md)).

## What is here

site/ holds the website exactly as it is served.

## Installing it on a server

One file, `setup.php` (the same file for every site in the ecosystem), installs this repository on its server. It
installs nothing until Henry proves he is present with his hardware key (touch and PIN, signing a fresh, single-use
challenge) and signs in to GitHub for that run only. Every run is recorded on a hash-chained log on the server.
`setup.php` arrives in this repository in its next commit.
